# Collect and qualify real ads

1. Extract official Facebook links from each selected brand's website. Call `ads_discover_advertisers` with the explicit store ID and brand name. Match Page alias/ID to the official link. Search hits alone are leads; locally hardcoded labels/test aliases are not identity evidence.
2. Both collection tools accept `activeStatus` (`ACTIVE`, `ALL`, `INACTIVE`) and `country` (`ALL` or a country code). Keep the primary market separate from expanded-market findings; do not label an ALL-country result as US delivery. Empty primary-market results require an expanded status/country check where useful, with library retention limitations disclosed. Call `ads_fetch_competitor_page` for the observed Page ID and research country. Read response counts and `nextCursor`. Fetch a bounded sample (normally up to three pages initially); stop once enough distinct relevant creatives are found. Do not present a paginated sample as exhaustive.
3. Use `ads_search_live_library` for a targeted brand + exact product subtype when initial Page samples contain unrelated categories. Vary one query using the actual subtype (for example the store's material/type), rather than assuming a broad keyword query finds everything. Search can return other brands: require advertiser and landing-domain association before keeping an ad. A different Page sending ads to the verified brand domain is evidence to investigate, not automatic proof based on a similar name.
4. A normal initial ten-brand sample may use about 50 provider requests. This is not a completion criterion. When the user requests a full follow-up, continue verified-Page pagination until the provider cursor is exhausted, repeated, or fails; record the terminal reason. Do not exhaust unrelated broad keyword results merely to increase counts. Stop on quota/auth/rate-limit errors. No purchasing credits, recurring crawl, live-ad mutations, or changes to static watchlists. Record requests and unconsumed cursors. An empty result is scoped to source, Page/query, country, status and retrieval time.
5. Open the landing page and inspect actual ad media. A product keyword can refer to a different use case (e.g. food-insulation blanket versus home blanket). Reject mismatches even when the brand is qualified. Inspect every carousel card headline, destination and media, even when the top-level copy/link does not mention the product. For mixed carousels, publish only verified card indices using `selectedCardIndices`; retain the original ad and original card numbering. Omit ambiguous cards, including media/destination mismatches.
6. Inspect images or sampled video frames; label the inspection honestly. Receiving a video URL is not watching the video or hearing audio. Where practical, probe media access and use downloaded public media for bounded inspection. Preserve provider CDN URLs for UI playback; explain expiry. Deduplicate identical creative files even if archive IDs differ, or explicitly report the distinction.
7. Publish via `ads_publish_competitor_research`: optional `verifiedAds` entries contain `brandDomain`, canonical `productEvidenceUrl`, `qualificationReason`, and the typed provider `ad`. Keep the real archive/Page IDs and source timestamps. `adCollection` records each brand's page IDs, identity sources, retrieval status/counts, selected count and limitations. `adInsights` must cite saved archive IDs and distinguish observations from original test hypotheses. Consult the live schema; never inject synthetic ads or claim reviewed audio from frames.
8. Read back the saved research and query the competitor ads tool to verify the same IDs are available to the UI. Check the UI shows media and retains format filters. Fewer brands with verified ads than website-qualified competitors is valid; report exact coverage and pending identities, not an invented ten-brand ad library.
